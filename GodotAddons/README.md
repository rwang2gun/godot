# Godot Addons

Shared addon workspace for Godot plugins that should stay independent from game projects.

## Addons

- `character_action_bp`: State-based action branching editor/runtime for Godot 4.

To use an addon in a game project, copy the addon folder into that project's `addons/` directory. For example:

```text
D:\claude\godot\GodotAddons\character_action_bp
```

goes to:

```text
<game-project>\addons\character_action_bp
```
