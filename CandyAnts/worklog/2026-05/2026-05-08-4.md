## 디자인 결정

- **Stage 3 토폴로지**: 단일 platform 1220px(x=600..1820), Home (1700,880) 우측, Candy (700,880) 좌측. Spawner alternation으로 +1/-1 ant 5:5 분할. -1 ants는 좌행 → Candy → 귀환. +1 ants는 우측 cliff(1820)로 추락(Phase 5 전까지 명시적 lost 처리 없음). Blocker 1마리 희생 → 9/9 saved (candy_hp=9 정밀 매칭).
- **BlockerSkill carrier 거부**: Builder는 finite(2.4s 후 자동 종료)지만 Blocker는 영구 정지 → 운반자 Blocker화 시 in_transit 영구 잔존 + 클리어 데드락. `state is WalkerState` + `not has_candy` 이중 가드로 차단. Codex HIGH 직접 대응.
- **AntSpawner alternation**: `spawn_direction_alternate=true`일 때 zero-based index — index 0 → +spawn_direction, 1 → -spawn_direction, 2 → +spawn_direction, ... `ant.direction` 설정을 `add_child` 전에 두어 `_ready()`의 WalkerState가 즉시 사용. Stage 1/2는 default false라 회귀 0.
- **BlockerHitbox 절대 direction 설정**: `flip()`이 아니라 `direction = sign(rel_x)`로 항상 멀어지는 방향. body_entered가 같은 ant에 다중 발화해도 결과 동일 — double-bump 본질적 차단. Blocker끼리는 둘 다 `state is WorkerState`라 핸들러가 무시 → 무한 루프 차단.
- **WorkerState.exit() 멱등**: blocker→Faller/Saved/Dead 어떤 경로로든 BlockerHitbox 비활성. 미래 phase에서 새 종료 경로 추가돼도 안전.
