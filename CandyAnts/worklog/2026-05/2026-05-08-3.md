## 결정 / 변경

- **수평 다리 결정 (사선 stair 폐기)** — 통합 테스트 첫 실행에서 발견 (ISSUES_LOG #S3 self MEDIUM). 사선 stair는 Builder ant만 teleport로 등반 가능, 다른 Walker ants는 16px 수직 wall로 인식하고 flip → 다리 못 건너감. WorkerState `_place_one_tile` 변경: `target_cell = cell + (dir, 1)` (forward + DOWN one row, ant 발 밑 행), `ant.global_position += (dir*16, 0)` (수평 이동). Stage02 geometry 동시 변경: gap 144→160px, platform 880px×2, 1920=880+160+880. 사유: Climber/슬로프 미도입 phase에서 사선은 비실용, ARCHITECTURE §5.3 "사선 12셀"은 Phase 8+ Climber 도입 후 정확화 예정.
- **자동화 테스트 = phase 통과 조건** (Codex HIGH #5) — `.tdd_bypass` 패턴(Phase 1·2)을 폐기. 대신 통합 테스트 1개 + per-file 스텁 7개로 TDD Guard와 Codex의 "no bypass" 권고를 동시에 충족. 사유: Phase 4+에서 매번 bypass 답습은 누적 invariant를 자동 검증 없이 흘려보내게 됨. 통합 테스트 driver 패턴 (`tests/StageNNHeadlessTest`) 표준화 — Phase 4 (Blocker)부터 동일 패턴 재사용.
- **Skill 베이스에서 const ID 제거** (구현 단계 발견) — GDScript 4가 `const`의 subclass shadowing을 parse error로 거부 (`The member "ID" already exists in parent class Skill`). 베이스에서 `const ID` 삭제, 각 서브클래스만 `const ID: String = "..."` 정의. SkillRegistry의 `script.ID` 접근은 그대로 작동. assert는 `id != ""`로 변경 (sentinel "_base_" 폐기). ARCHITECTURE §4.2의 베이스 const 패턴은 GDScript 4 호환 위해 갱신 필요 (deferred, plan에 메모).
- **Builder = 0.2s/tile × 12 tiles** — TICK_SECONDS=0.2, TOTAL_TILES=12. 총 ~2.4초 다리 형성. 사유: 즉시 placement는 player feedback 부재. 0.2s tick은 Stage02HeadlessTest의 200s 안에 충분.
- **Builder placement Terrain 검색** — WorkerState가 ancestor 트리를 거슬러 올라가며 `Terrain` 노드 검색 (`get_node_or_null("Terrain")` + `is Terrain` 체크). Stage02에서 World 자식으로 Terrain 노드 위치. 사유: 명시 NodePath export는 ant 인스턴스에 stage-specific 정보 주입 필요 — group/ancestor 검색이 더 깨끗.
