# Skill Icons

Runtime skill icons are PNG files generated by `scripts/tools/generate_skill_png_icons.py`.
Button icons are stored directly in this folder. Cursor-only variants with a top-left pointer arrow are stored in `cursors/`.

Current registered skill icon set:

- `basher.png`
- `blocker.png`
- `bridge.png`
- `builder.png`
- `climber.png`
- `cutter.png`
- `digger.png`
- `distributor.png`
- `floater.png`
- `leaf_jump.png`
- `sand_mound.png`

Button background colors are grouped by skill category:

- Sign install: `basher`, `digger`, `cutter`, `sand_mound`
- Settle/exit: `blocker`, `floater`
- Armed auto-trigger: `climber`, `bridge`, `builder`
- Device install: `leaf_jump`

The older SVG placeholders remain in this directory as archived reference assets, but runtime code should use PNG icons.

To regenerate:

1. Run `python scripts/tools/generate_skill_png_icons.py` with Pillow available.
2. Open Godot once, or run the headless editor, so `.png.import` files are refreshed.
3. Run the skill toolbar/icon smoke tests.
