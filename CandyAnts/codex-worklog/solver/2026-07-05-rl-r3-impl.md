### mdp.py — R3_OBS_SCHEMA (관측 확장, 전량 pin)
- **공간 채널 `TRACE_CHANNELS`**(C_trace=4, 고정 순서) = `[visit_walk, loss, visit_carry, pickup_goal]`.
  `trace_channels(res)` = 결정론 rasterize(model._samples/_died_water read-only 재사용): walk/carry 밀도
  `/DENSITY_DENOM(=7000)`, loss/pickup 마커 `/total_ants`, clip(0,1), off-grid 경계 clamp, absent=전0.
- **집계 스칼라 `TRACE_SCALARS`**(7종, 고정 순서) = `[best_goal_dist, retired_{total,water,fall},
  picked_total, saved, verdict_code]`. `verdict_code` enum pin `{absent:0..error:4}` `/4`. 분모=레이아웃/
  스테이지 상수(result 파생 분모 금지, R1-H1). `model.best_goal_dist/count_retired` read-only.
- **`obs_schema_digest`** = 채널·스칼라 순서·verdict enum·정규화 분모 규칙·dtype·absent 규칙의 sha256
  (스테이지-무관 상수) = ckpt·산출물·verify-r3 대조 키. `flat_dim_r3 = flat_dim + 7`.

### train.py — refine 오케스트레이션
- **`make_policy_r3`**: r2 CNN(5ch) + trace 공간 채널 concat(→9ch) + trace 스칼라 flat append.
- **`Rollouter`**(memo): `memo_key = sha256(exec_config_digest, 정규화 lowered plan)`. `_exec_config_digest`
  = 멤버 전량 명시(stage_resource full content hash[stage+layout+scene .tres 바이트]·skill_meta·vocab·
  grammar·fixed_fps·train/replay_deadline·trace_schema·godot binary·driver script rev·protocol). memo는
  **처리량만** — verdict/보상/샘플링 불변. `--no-memo`로 끔. 회계=requests/total_rollouts/distinct/hit_rate.
- **`_sample_batch_refine`**(depth-lockstep): 배치 각 에피소드가 P_0..P_L을 롤아웃(memo+N-env 병렬)하며
  trace 관측→액션. SUBMIT/max_len=terminal. 최종 롤아웃(=마지막 obs 롤아웃 재사용)만 보상. **L+1 롤아웃/
  에피소드**(blind R0~R2의 1회 대비). 스텝0 SUBMIT 마스킹 유지.
- **보상(primary)** = R2와 **동일 형태** = `R_d4 + R1_terminal_shaping`(계상 1회, 최종 롤아웃) — **trace는
  obs만 바꾸고 보상 형태 불변**(plan 설계). `_episode_logp_r3`(SIL, prefix memo 재사용).
- **dense fallback**(`--dense-shaping`, acceptance 6): `_dense_terms` = `F_t=γφ(P_{t+1})−φ(P_t)`, γ=1,
  terminal φ=0 → Σ=−φ(P_0)(정책-불변). terminal trace-shaping off(이중계상 차단).
- **ckpt r3**(`candyants-rl3-ckpt-v1`): model_cfg에 obs_schema_digest/refine/in_channels 포함(r2 정책과
  shape 비호환). `_ckpt_compat`/`_model_cfg` refine-aware. memo는 **미직렬화**(재개 시 결정론 재구성).
- **`_write_r3_artifact`**: variant별 분리 파일(primary/dense_fallback/trace_blind clobber 방지) + outcome
  enum(`pass/model_fail/throughput-pin-invalid`) + THROUGHPUT_FLOOR 회계 + r3_mechanical_pass.
- **`verify_r3`**: mode↔pin 정합(primary=R3_PRIMARY_PIN/dense=R3_DENSE_PIN) + obs 계약(digest·채널/스칼라
  순서) + memo_key 스키마 + config pin 값-대조 + 처리량 회계 + outcome별 분기(pass=predicate∧replay×2∧
  saved==hp) + ckpt 무결 + dense telescoping + **검증자 측 live trace preflight**.
