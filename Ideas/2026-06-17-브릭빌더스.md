# 아이디어 3 — 브릭빌더스 (Brick Builders)

🌱 새싹 · 2026-06-17

## 한 줄
**레고 설명서**에서 영감 — 주어진 블록(레고/테트로미노)을 보이는 이미지 칸에 올바르게 배치하는 퍼즐. 스테이지들이 모이면 한 챕터가 하나의 완성된 입체 브릭이 된다.

## 코어 루프 (스테이지 단위)
- 화면에 **목표 이미지(채워야 할 칸 = 도안)**가 제시됨.
- 플레이어는 **주어진 블록 세트**(레고 조각 또는 테트로미노)를 받아, 도안 칸에 정확히 들어맞게 배치.
- 설명서를 따라 조립하듯 "어디에 뭘 끼우는가"를 푸는 배치 퍼즐.

## 핵심 훅 — 레이어 → 완성 모델 (메타 구조)
- **한 챕터의 각 스테이지 = 완성될 브릭의 한 레이어(층).**
- 스테이지를 풀 때마다 그 층이 완성됨.
- **챕터 완료 시 레이어들이 위로 쌓이며 합쳐져** 하나의 완성된 입체 블록 모델을 드러냄 (조립 연출).
- → 플레이어는 풀면서 자기가 *무엇을 만들고 있었는지*를 마지막에 깨닫게 됨 (설명서를 끝까지 따라간 보상감).

## 수집 메타
- 완성된 블록 모델은 **수집되어 메인 메뉴에 반영** (진열장/컬렉션).
- 챕터를 깰수록 메인 메뉴에 모델이 늘어나는 진척 시각화 → 계속할 동기.

## 다듬기 포인트 (미정)
- 블록 종류: 레고식(요철 결합) vs 테트로미노식(격자 채우기)? 둘 다 vs 챕터별 다름?
- 정답이 유일한가, 여러 배치가 허용되나? (자유도 vs 명확한 정답)
- 회전/뒤집기 허용 여부 → 난이도 조절 레버.
- 레이어가 위로 쌓이는 구조라면 2.5D/아이소메트릭 표현이 자연스러울 수도.
- 오답/제약: 안 맞는 칸 배치 시 피드백, 조각 부족/잉여 처리.

## 열린 질문
- 타깃: 캐주얼 모바일? (짧은 스테이지 + 수집 메타는 모바일 친화적)
- 한 챕터 = 몇 레이어(스테이지)? 모델 복잡도와 직결.
- 콘텐츠 생산: 완성 모델 → 레이어 분해 → 스테이지 도안을 **툴로 자동 분해**할 수 있나? (저작 파이프라인 핵심)

## 비고
- 셋 중 가장 **고유 메타 구조**가 뚜렷한 아이디어 — "퍼즐을 풀면 무언가가 조립된다 + 수집"이 차별점.
- 도안 분해 툴이 있으면 콘텐츠 양산이 쉬워짐 (CandyAnts 레벨 에디터 경험 재사용 여지).
