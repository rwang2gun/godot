# Ideas

게임 아이디어를 자유롭게 모아두는 폴더. 특정 프로젝트(CandyAnts 등)에 묶이지 않은 발상·메모를 `.md`로 보관한다.

## 쓰는 법
- 아이디어 하나당 파일 하나: `YYYY-MM-DD-<짧은-제목>.md` (예: `2026-06-17-사탕-보스전.md`)
- 다듬어지지 않아도 됨 — 떠오른 즉시 적어두는 게 목적
- 특정 프로젝트로 채택되면 해당 프로젝트의 `docs/`로 옮기고 여기엔 한 줄 포인터만 남겨도 됨

## 상태 표기(선택)
- 🌱 새싹 (방금 적음) · 🔨 검토 중 · ✅ 채택 · 🗄️ 보류
